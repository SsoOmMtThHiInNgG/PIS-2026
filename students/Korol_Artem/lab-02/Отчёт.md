## Часть 1. Архитектурная диаграмма

### Описание сервиса

Event Service управляет жизненным циклом мероприятий:
- созданием событий;
- публикацией расписания;
- продажей билетов;
- регистрацией участников;
- отображением спикеров.

Основные сущности:
- Event (мероприятие)
- Ticket (билет)
- Schedule (расписание)
- Speaker (спикер)

## Бизнес-правила

1. Нельзя купить билет на завершённое мероприятие.
2. Количество билетов ограничено вместимостью площадки.
3. Спикер не может быть назначен на два события одновременно.
4. Время начала мероприятия должно быть раньше времени окончания.
5. После успешной оплаты билет получает уникальный QR-код.

## Часть 5. Infrastructure Layer (Инфраструктурный слой)

### Входящий адаптер: REST API

### TicketController

```java
@RestController
@RequestMapping("/api/tickets")
public class TicketController {

    private final BuyTicketUseCase buyTicketUseCase;

    public TicketController(BuyTicketUseCase buyTicketUseCase) {
        this.buyTicketUseCase = buyTicketUseCase;
    }

    @PostMapping
    public Long buy(@RequestBody BuyTicketRequest request) {
        return buyTicketUseCase.buy(request.toCommand());
    }
}
```

---

## Эндпоинты

- POST /api/tickets — покупка билета
- GET /api/events — получение списка мероприятий
- GET /api/schedule/{id} — получение расписания

## Исходящий адаптер: Repository

### InMemoryEventRepository

```java
public class InMemoryEventRepository implements EventRepository {

    private final Map<Long, Event> storage = new HashMap<>();

    @Override
    public Event save(Event event) {
        storage.put(event.getId(), event);
        return event;
    }

    @Override
    public Event findById(Long id) {
        return storage.get(id);
    }
}
```

---

## Принцип работы

Данные временно хранятся в памяти приложения через HashMap.

## Часть 6. Dependency Injection (DI)

### DependencyInjectionConfig

```java
@Configuration
public class DependencyInjectionConfig {

    @Bean
    public EventRepository eventRepository() {
        return new InMemoryEventRepository();
    }

    @Bean
    public CreateEventUseCase createEventUseCase(EventRepository repository) {
        return new EventService(repository);
    }

    @Bean
    public EventController eventController(CreateEventUseCase useCase) {
        return new EventController(useCase);
    }
}
```

---

## Как работает DI

Spring создаёт объекты (beans) и автоматически внедряет зависимости через конструкторы.
