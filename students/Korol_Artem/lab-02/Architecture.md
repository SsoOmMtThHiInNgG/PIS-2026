# Архитектурная диаграмма

## Диаграмма слоёв

```text
┌──────────────────────────────────────────────────────────────┐
│                     Infrastructure Layer                     │
│  ┌──────────────────┐   ┌──────────────────────────────────┐ │
│  │ REST API         │   │ EventRepository (DB/InMemory)    │ │
│  │ Controllers      │   │ TicketRepository                 │ │
│  └───────────┬──────┘   │ ScheduleRepository               │ │
│              │          │ SpeakerRepository                │ │
│              │          └──────────────────────────────────┘ │
└──────────────┼───────────────────────────────────────────────┘
               │
               ▼
┌──────────────────────────────────────────────────────────────┐
│                     Application Layer                        │
│  ┌──────────────────┐   ┌──────────────────────────────────┐ │
│  │ In Ports         │   │ Out Ports                        │ │
│  │ (Use Cases)      │   │ (Repositories, Notifications)    │ │
│  └───────────┬──────┘   └──────────────────────────────────┘ │
│              │                                               │
│  ┌───────────▼────────────────────────────────────────────┐  │
│  │   EventService (управление мероприятиями)              │  │
│  │   TicketService (продажа билетов)                      │  │
│  │   ScheduleService (расписание событий)                 │  │
│  │   SpeakerService (работа со спикерами)                 │  │
│  └────────────────────────────────────────────────────────┘  │
└───────────────────────────┬──────────────────────────────────┘
                            │
                            ▼
┌──────────────────────────────────────────────────────────────┐
│                         Domain Layer                         │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐        │
│  │ Event        │  │ Ticket       │  │ Schedule     │        │
│  │ (Aggregate)  │  │ (Entity)     │  │ (Entity)     │        │
│  └──────────────┘  └──────────────┘  └──────────────┘        │
│  ┌──────────────┐                                            │
│  │ Speaker      │                                            │
│  │ (Entity)     │                                            │
│  └──────────────┘                                            │
└──────────────────────────────────────────────────────────────┘
```

### Описание портов и адаптеров

| Тип | Название | Назначение |
| --- | --- | --- |
| **Входящий порт** | ICreateEventUseCase | *Интерфейс для создания мероприятия* |
| **Входящий порт** | IBuyTicketUseCase | *Интерфейс покупки билетов* |
| **Входящий порт** | IGetScheduleUseCase | *Интерфейс получения расписания* |
| **Исходящий порт** | IEventRepository | *Интерфейс доступа к мероприятиям* |
| **Исходящий порт** | ITicketRepository | *Интерфейс хранения билетов* |
| **Исходящий порт** | IScheduleRepository | *Интерфейс работы с расписанием* |
| **Исходящий порт** | ISpeakerRepository | *Интерфейс хранения спикеров* |
| **Входящий адаптер** | EventController (REST) | *REST API для мероприятий* |
| **Входящий адаптер** | TicketController (REST) | *REST API для покупки билетов* |
| **Входящий адаптер** | ScheduleController (REST) | *REST API для расписания* |
| **Входящий адаптер** | SpeakerController (REST) | *REST API для спикеров* |
| **Исходящий адаптер** | InMemoryEventRepository | *Хранилище мероприятий в памяти* |
| **Исходящий адаптер** | InMemoryTicketRepository | *Хранилище билетов в памяти* |
| **Исходящий адаптер** | InMemoryScheduleRepository | *Хранилище расписания в памяти* |
| **Исходящий адаптер** | InMemorySpeakerRepository | *Хранилище спикеров в памяти* |
