## Цель работы

Изучить технологию Protocol Buffers и механизм удалённого вызова процедур gRPC для организации взаимодействия между сервисами.

---

## Вариант №15 — Сервис мероприятий и билетов 🎫

**Питч:** Пользователь может создавать мероприятия, публиковать их и приобретать билеты.

**Ядро домена:**

* Мероприятия (Event)
* Билеты (Ticket)
* Расписание (Schedule)
* Докладчики (Speaker)

---

## Ход выполнения работы

### 1. Event Service

**Bounded Context:** Управление мероприятиями.

Сервис отвечает за публикацию мероприятий и получение информации о них.

Реализованы следующие операции:

* PublishEvent()
* GetEvent()

---

### 2. Ticket Service

**Bounded Context:** Управление билетами.

Сервис отвечает за создание билетов и предоставление информации о них.

Реализованы следующие операции:

* CreateTicket()
* StreamTickets()

---

### 3. Protocol Buffers

Для описания контрактов взаимодействия между сервисами использован язык Protocol Buffers.

Создан общий файл:

```protobuf
syntax = "proto3";

service EventService
service TicketService
```

В файле описаны:

* сообщения запросов;
* сообщения ответов;
* сервисы;
* RPC-методы.

---

### 4. gRPC

Для организации взаимодействия между сервисами использована технология gRPC.

Реализованы:

#### Unary RPC

Получение одного ответа на один запрос:

```text
PublishEvent()
GetEvent()
CreateTicket()
```

#### Server Streaming RPC

Передача потока данных от сервера клиенту:

```text
StreamTickets()
```

---

### 5. gRPC Server

В системе реализованы следующие gRPC-сервисы:

#### EventGrpcService

Предоставляет операции:

* публикация мероприятия;
* получение информации о мероприятии.

#### TicketGrpcService

Предоставляет операции:

* создание билета;
* потоковая передача списка билетов.

---

### 6. gRPC Client

Для проверки работы сервисов реализированы клиенты:

#### EventGrpcClient

Позволяет выполнять вызовы:

* PublishEvent();
* GetEvent().

#### TicketGrpcClient

Позволяет выполнять вызовы:

* CreateTicket();
* StreamTickets().

---

### 7. Сборка и запуск проекта

Сервисы были успешно собраны с использованием Maven.

Команда сборки:

```bash
mvn clean install
```

Результат:

```text
BUILD SUCCESS
```

Запуск сервисов выполнялся командой:

```bash
mvn spring-boot:run
```

После запуска:

* Event Service работает на порту 8080;
* Ticket Service работает на порту 8081.

## Вывод

В ходе выполнения лабораторной работы были изучены технологии Protocol Buffers и gRPC. Для предметной области управления мероприятиями и билетами были реализованы два независимых сервиса: Event Service и Ticket Service.
